# 图文混排飞书文档 Skill

把妙记、会议纪要、视频、录音稿、PPT、Deck、HTML、PDF、图片和文字，整理成图文混排飞书文档：

> 一张有意义的画面 → 一整段对应的视频稿 → 下一张画面 → 下一段视频稿

## 它解决什么问题

普通转写会产生一面墙一样的逐句字幕；普通总结又会丢掉演讲者的推理过程和画面证据。这个 Skill 把两者连起来：保留原始讲解的事实和逻辑，同时把正在讲的 Deck、屏幕操作或视频关键帧放到对应文字旁边。

它特别适合处理：

- 一边讲话、一边演示 PPT 或操作屏幕的视频
- 妙记和演示文稿分散在不同文件里的会议
- 小红书、公开视频或本地录音视频
- 需要分享给别人阅读，而不是让别人重新看完整视频的内容

## 默认成稿效果

默认输出是可读的视频稿，不是原始字幕堆：

- 去掉逐句时间码、时间范围和“插图占位”文字
- 清理“嗯、啊、诶、那个、然后”等无意义口语词、重复片段和明显识别错误
- 把相邻字幕合并成自然的一整段
- 保留事实、数字、名字、技术名词、案例、观点和因果关系
- 每张图紧跟一段对应的讲解
- 图片说明默认只描述画面，不暴露临时访问 Token

如果需要原始逐字稿、字幕、时间轴或按秒对应，明确说“保留时间码”即可切换模式。

## 小红书链接怎么处理

不用用户手动复制完整长链接。Agent 会自行对小红书分享短链发起真实 GET 请求并跟随重定向，然后从公开笔记页面中提取标题、作者、封面、视频地址和页面自带字幕，再用字幕作为叙事来源、用视频关键帧作为画面证据。

重定向参数和带签名的临时媒体地址只在内部处理，不写入最终文档，也不依赖无关的第三方下载站。

## 安装

```bash
git clone https://github.com/liangshimiao2691-wq/creating-illustrated-feishu-doc.git ~/.claude/skills/creating-illustrated-feishu-doc
```

其他 Agent 只要把仓库里的 `SKILL.md`、`references/` 和 `agents/` 放入它的 Skill 目录即可。不同 Agent 的安装目录可能不同。

生成真正的飞书文档，需要宿主 Agent 具备飞书/Lark 文档能力，并完成 `lark-cli` 用户授权。没有飞书能力时，可以让宿主 Agent 输出本地 Markdown 或 HTML 版本。


## 核心原则

- 忠于素材，不把图文稿偷换成泛泛总结
- 先放画面，再放对应讲解
- 轻度口语清理，不擅自改写观点
- 时间码保留在内部对齐和校验中，默认不展示
- 不虚构缺失的字幕、页面文字、人物身份或画面含义
- 保留公开来源，保护临时访问参数
